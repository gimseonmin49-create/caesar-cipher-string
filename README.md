# caesar-cipher-string

시저 암호로 문자열 전체를 암호화하는 C 프로그램입니다. (2단계)

## 기능
- 대문자 문자열과 미는 칸 수를 입력받아 암호화
- 예: HELLO, 3 → KHOOR
- 예: XYZ, 3 → ABC (Z 다음에 A로 순환)

## 원리
- 문자열은 char 배열이고 끝에 '\0'이 붙음
- for문으로 '\0'을 만날 때까지 글자마다 (글자 - 'A' + key) % 26 적용
- scanf("%99s")로 입력 길이를 제한해 버퍼 오버플로우 방지

## 한계
- 대문자, 띄어쓰기 없는 문자열만 지원 (소문자, 음수 key는 미처리)

## 이전 단계
- 1단계: caesar-cipher (글자 하나 암호화)

## 환경
